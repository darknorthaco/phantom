## 🚀 **Quick Start**

### **Web UI Setup**
```bash
# Clone the repository
git clone https://github.com/darknorthaco/redblue
cd redblue/matrix-web-ui

# Deploy locally
./deploy-matrix-ui.sh --python-server

# Open browser
open http://localhost:3000
```

### **Android App Setup**
```bash
# Navigate to Android app
cd redblue/phantom-matrix-android

# Build APK
chmod +x build-android.sh
./build-android.sh

# Install on device
adb install android/app/build/outputs/apk/debug/app-debug.apk
```

### **Connect to Phantom Backend**
```bash
# Both UIs connect to your Phantom system
# Default: ws://192.168.1.103:8765
# Configure in settings for your network
```
